prosemirror-inspector

See inside a ProseMirror editor while it runs.

Inspect the document, the selection, and every transaction. Profile plugin hooks and dispatch phases, and give coding agents read-only access to the same evidence.

Open the invoice workbench →

A multi-page Tiptap invoice with the inspector built in. Press ⌘⇧D outside the editor, or use the button at the bottom right.

What to try in the workbench

  • Run a scenario from the left sidebar and follow its hint to the right panel.
  • Load 2,000 rows from the load lab and watch typing in Performance.
  • Run "Agent reads the invoice" and open the WebMCP tab.
  • Export a recording and open it in the read-only viewer.
  • Pick More › Collaborate in two tabs, then Open as second user. The tabs sync over BroadcastChannel, so both must be in this browser.
